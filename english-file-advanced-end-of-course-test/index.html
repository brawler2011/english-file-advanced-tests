English File Advanced: End-of-course Test

Главная › English File Advanced: End-of-course Test
Аудиозаписи к заданиям на аудирование в архиве не сохранились, поэтому в этих заданиях плеер пустой.

Данный тест (Englush File Advanced End-of-Course test) идеально подходит для того, чтобы проверить и подтвердить свои знания английского языка на продвинутом уровне. В этом тесте проверяются навыки аудирования, чтения, лексики, грамматики и произношения на уровне Advanced. Для выполнения всех заданий Вам понадобится 60 минут.
Для чистоты результата не разрешается пользоваться какими- либо вспомогательными материалами, включая словари, справочники, онлайн переводчики и т.д.

После выполнения заданий каждого слайда необходимо нажать кнопку “Check” для проверки и подсчета количества балов. Статистика правильно выполненных заданий по всему тесту будет доступна для вас на последнем слайде “Summary”. Чтобы перейти в полноэкранный режим, нажмите на стрелочки в правом нижнем углу 😉 Успехов!
