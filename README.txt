Статический сайт с тестами English File Advanced.

Локально: python3 -m http.server 8000  (в этой папке), затем http://127.0.0.1:8000/
Открыть index.html двойным щелчком нельзя — плееру H5P нужен веб-сервер.
Хостинг: любой статический (GitHub Pages, Netlify, Cloudflare Pages, обычный хостинг) — просто загрузить содержимое папки.
